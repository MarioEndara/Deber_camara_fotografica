Photo Gallery App con Ionic Angular
Aplicación movil desarrollada con Ionic

Caracteristicas
Captura de fotos ( Integración con ´@capacitor/camera´ sirve para tomar fotografias en tiempo real
Almacenamiento persistente (Uso ´@capacitor/filesystem´ y ´@capacitor/preferences´ para guardar las fotos en el dispositivo
Gestion de galeria( Confimación y eliminación de fotografías seleccionadas)
Compatibilidad multiplataforma(Funcionamiento tanto en entorno Web/PWA como en Andoid compilado nativamente)

Tecnologías utilizadas
Ionic + Angular (Framework)
Lenguaje(TypeScript/HTML5/SCSS
Plugins 
´@capacitor/camera
@capacitor/filesystem
@capacitor/preferences
